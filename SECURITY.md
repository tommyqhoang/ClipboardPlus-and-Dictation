# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private
reporting: **Security -> Report a vulnerability** on
https://github.com/tommyqhoang/ClipboardPlus-and-Dictation/security/advisories/new
or email hoangtommyquoc@gmail.com with the subject "Clipboard+ security".

Include the version, your OS, and steps to reproduce. You should get an
acknowledgement within 5 business days. Please allow up to 90 days for a fix
before public disclosure; we will credit you in the release notes unless you
prefer otherwise.

## Scope

In scope: the desktop app, its installers and update path, and the release
pipeline. Out of scope: vulnerabilities in third-party components that are
not exploitable through Clipboard+ (report those upstream).
