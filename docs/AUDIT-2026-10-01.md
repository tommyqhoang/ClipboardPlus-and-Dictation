# Desktop review — October 1, 2026

## Scope and findings

Reviewed the macOS menu bar, Windows/Linux tray, shared Settings and clipboard
controls, shortcut registration, clipboard capture and recovery, login startup,
macOS app replacement, and the repository's cross-platform verification gates.

### macOS startup and menus

The installed Mac's loaded LaunchAgent still referenced the removed
`Contents/MacOS/WhisperDictation` launcher, although its plist on disk named the
current `Contents/MacOS/Clipboard+` launcher. The unload command passed a label
where launchctl expected a plist path. It now uses the full service target and
reloads an idle job even when the plist is already current.

Left-click retains the history popover. Right-click and Control-click now expose
Settings, Quit, Open at Login, clipboard pause/resume and history actions, and
dictation actions when enabled. Missing artwork has a visible text fallback.
Escape clears a search before dismissing the popover. Clearing history uses the
shared confirmation dialog, including scope and favorite retention.

### Cross-platform behavior and reliability

- Tray primary actions open history when enabled, otherwise the main window.
- Recent-history actions now work with pystray's actual callback adapter.
- Start/stop is unavailable while transcription is already in progress.
- Open at Login is available in shared Settings on all three platforms.
- Timed pauses refresh when they expire, including without a settings write.
- Capture startup failures retry with backoff; storage recovery recreates the
  watcher instead of leaving initialization half complete.
- Quitting also stops a capture service adopted after a previous app crash.
- macOS rechecks pasteboard identity after reading content, avoiding capture of
  a replacement copy whose privacy markers were not checked.
- Shortcut presets saved in Settings take effect in the running Mac app;
  rejected choices restore the prior setting. Unreadable shortcut events never
  start the microphone. Windows callback failures leave the hotkey loop running.
- Menu refresh failures are logged without ending subsequent refreshes.
- Closing the recording pill cancels its pending frame callback and tolerates
  repeated close requests. GUI test fixtures explicitly collect Tk objects on
  the UI thread so later background work cannot finalize their Tcl interpreters.

### Installation and quality gates

The DMG helper stages and verifies a replacement before moving the installed
app, retains the prior app for rollback, and refuses unrelated bundles or an app
reported as running. Regression tests execute the embedded installer with fake
system commands to cover copy, signature, and launch failures.

CI and the local Docker gate now install the GUI dependencies so the real
pystray callback adapter is exercised. Local shell checks include release
packaging scripts. Docker/install copies omit build output and local environments.
Optional native UI dependencies have consistent mypy treatment whether installed
or absent. No dependency versions were changed.

## Release boundaries

These source changes do not update the installed Mac copy automatically. The
repository requires approval before running `./install.sh` for that copy.

Automated tests and platform typechecks do not establish physical Windows or
Linux desktop behavior, microphone permissions/audio quality, live provider or
account sync behavior, or macOS signing/notarization. Those remain release
acceptance checks. The local PyInstaller build is a packaging check; it is not a
complete signed release with bundled speech/media dependencies.
